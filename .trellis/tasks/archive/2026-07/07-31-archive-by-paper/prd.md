# 实现存档功能——按论文标题归档对话、翻译等生成内容

## Goal

用户可以将当前论文的所有 AI 生成内容（总结、概念解释、质疑、翻译、对话）一键存档到浏览器本地存储（IndexedDB），并可随时查看、恢复、删除、导出或导入历史存档。

## Confirmed Facts

- 5 种 AI 内容：summarize / explainConcepts / critique / translate / chat
- 分析结果在 `aiPane.js` 的 `savedResults`（模块作用域，非持久化）
- 对话消息在 `store.messages` 数组
- 已有按单个 tab 下载 .md/.pdf 的功能
- 切换论文时所有生成内容丢失（新 PDF → 新 state）
- 纯前端单 HTML 应用，无后端，`localStorage` 仅存设置
- Paper 元数据含 title、authors、nPages、name（文件名）

## Decisions Made

- D1: 存档存储方式 → IndexedDB 浏览器持久化
- D2: 支持从存档恢复当前会话（PDF 渲染无法恢复是可接受的限制）
- D3: UI 模式 → 顶栏按钮，点击弹出管理对话框（与设置面板模式一致）
- D4: 支持从 IndexedDB 导出存档为 .json 文件备份
- D5: 支持从 .json 文件导入存档到 IndexedDB
- D6: 点击按钮始终打开管理对话框（统一入口），不区分有无历史

## Requirements

- R1: 一键存档当前论文的所有已生成内容到 IndexedDB
- R2: 存档以论文标题为标识（fallback 到文件名）
- R3: 存档内容包含所有已生成的 tab 结果（有内容的才包含，未生成的不包含）
- R4: 对话框内可查看历史存档列表
- R5: 归档数据包含：论文元信息 + 各分析结果 + 对话记录 + 存档时间
- R6: 可从历史存档恢复到当前会话（恢复 savedResults + messages + paper 元信息）
- R7: 可删除历史存档（需确认）
- R8: 可导出单条存档为 .json 文件备份
- R9: 可从 .json 文件导入存档到 IndexedDB
- R10: 同一论文多次存档不覆盖，每条独立记录（以时间戳区分）

## Acceptance Criteria

- [ ] AC1: 顶栏存在"存档"按钮，无任何生成内容时禁用
- [ ] AC2: 点击按钮弹出管理对话框
- [ ] AC3: 点击"保存当前"将当前内容写入 IndexedDB，列表即时刷新
- [ ] AC4: 存档列表每条显示论文标题、各内容类型有无标记、存档时间
- [ ] AC5: 可删除历史存档（需确认对话框）
- [ ] AC6: 可恢复历史存档到当前会话（savedResults + messages + paper 元信息）
- [ ] AC7: 可导出单条存档为 .json 文件
- [ ] AC8: 可导入 .json 文件到 IndexedDB，列表即时刷新
- [ ] AC9: 同一论文多次存档不覆盖，每条独立
- [ ] AC10: 关闭对话框后应用状态正确

## Out of Scope

- PDF 原始文件的存档/恢复（IndexedDB 不存 PDF 二进制）
- 跨设备同步
- 存档内容全文搜索
