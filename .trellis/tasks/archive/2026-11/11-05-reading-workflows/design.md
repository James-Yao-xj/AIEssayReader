# Design
Keep native ESM and single HTML. Persist paper text/pages/fingerprint, result statuses and incomplete messages in versioned archives; keep PDF binary user-supplied. Add stable page chunk citations and navigation events. Treat task progress as document-owned and resumable; require explicit opt-in before multiple AI calls. Use partial-result statuses across UI/archive. Compress oversized old turns in bounded fragments. Incremental rendering caches stable Markdown token prefixes; final render resolves references. Extract layout into pure utility. Add real browser fixtures and tests, document unsupported layouts.
